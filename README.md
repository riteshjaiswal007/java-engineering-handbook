# Java Interview Preparation

A structured collection of Java programming concepts, coding challenges, and interview preparation material for Senior Software Engineer, Lead Developer, and Staff Engineer roles.

## 🎯 Objective

To strengthen problem-solving skills and prepare for technical interviews through practical examples, complete Java implementations, and clear explanations.

## 🛠️ Technology Stack

- Java 17
- Object-Oriented Programming
- Java Collections Framework
- Java 8+ Stream API
- Data Structures and Algorithms
- Multithreading and Concurrency
- Spring Framework and Spring Boot
- Microservices

## 📚 Topics Covered

### 1. Core Java
- OOP concepts
- String handling
- Exception handling
- Collections Framework
- Generics
- Java 8, 11, 17 and newer features
- JVM, JDK and JRE

### 2. Java Collections
- List, Set and Map
- HashMap and ConcurrentHashMap
- ArrayList and LinkedList
- HashSet and TreeSet
- PriorityQueue
- Comparable and Comparator

### 3. Java Stream API
- filter(), map() and flatMap()
- sorted() and distinct()
- groupingBy() and partitioningBy()
- Collectors.toMap()
- Frequency counting
- Duplicate element detection

### 4. Data Structures and Algorithms
- Arrays and Strings
- Linked Lists
- Stack and Queue
- Hashing
- Binary Search
- Trees and Binary Trees
- Heap and Priority Queue
- Dynamic Programming
- Recursion and Backtracking

### 5. Object-Oriented Design
- SOLID Principles
- Design Patterns
- Abstraction and Encapsulation
- Inheritance and Polymorphism

### 6. Spring and Microservices
- Spring Core and Dependency Injection
- Spring Boot
- REST APIs
- Spring Data JPA and Hibernate
- Transactions
- Microservices Architecture

## 💻 Code Standards

- Java 17 compatible implementations
- Meaningful class and method names
- Complete runnable examples wherever applicable
- Time and space complexity analysis
- Practical examples and interview-oriented explanations

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/riteshjaiswal007/java-interview-preparation.git
   ```

2. Open the project in IntelliJ IDEA.

3. Make sure Java 17 or later is configured.

4. Run the required Java class.
